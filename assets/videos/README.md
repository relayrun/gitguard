# Git Guard overview videos

All eight introductions (en, zh-CN, ja, de, fr, es, pt-BR and ru) are 40-second MP4 exports with matching PNG covers. Each GitHub README embeds the matching GitHub-hosted video attachment and retains a direct MP4 download link. The repository copies below remain available to local readers and other hosts. All exports share the accepted action effects and contain no background music.

These are presentation exports, not recordings of repository operations or evidence of server enforcement. They contain short action effects and no background music. Editable animation sources and original sound recordings are not included here.
