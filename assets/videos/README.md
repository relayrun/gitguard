# Git Guard overview videos

All eight introductions (en, zh-CN, ja, de, fr, es, pt-BR and ru) are 40-second MP4 exports with matching PNG covers. Each README links to the video in its own language. All exports share the accepted action effects and contain no background music.

These are presentation exports, not recordings of repository operations or evidence of server enforcement. They contain short action effects and no background music. Editable animation sources and original sound recordings are not included here.

## Sound credits

Transfer effect adapted from [Short Whoosh, 13x by Kinoton](https://freesound.org/people/Kinoton/sounds/427979/), released under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The sample was cropped, filtered, sped up and placed in stereo at reduced gain. Rejection and completion effects use original synthesis.
