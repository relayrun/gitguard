<a id="homepage-placement-and-language"></a>

## ホームページ上の位置と言語

40 秒の紹介を README の言語一覧の直後、中心となる説明と日常四ステップの前に置きます。英語見出しは “Git Guard in 40 seconds”、中国語見出しは “40 秒了解 Git Guard” です。製品概要であり、完全な設定チュートリアルではありません。

選択された README と同じ言語を使います。既定の英語 README は英語 MP4、簡体字中国語と日本語はそれぞれの MP4 にリンクします。動画だけの言語選択を追加しません。README の切り替えで動画も選ばれます。ドイツ語、フランス語、スペイン語、ブラジルポルトガル語、ロシア語にも完成した動画があり、八組の README と動画はこのローカルパッケージに含まれます。

<a id="delivery-and-playback"></a>

## 配布と再生

- 配布は MP4 のみです。PNG 表紙は再利用用素材として残し、アニメーション GIF にはしません。編集可能な構成、共通アート、翻訳テキストは制作環境に置き、選定した出力だけを配布します。
- 各言語の GitHub README は、独立した段落の動画添付 URL でプレーヤーを埋め込み、その下に MP4 の直接ダウンロードリンクを残します。同梱 MP4 と言語別の添付 URL は動画素材の説明に記載します。他の Markdown ビューアーではリンクのみになる場合があります。
- README は独自 JavaScript を実行できず、ブラウザー言語や IP で動画を選べません。リンク付き表紙はファイルへ移動し、通常の HTML video タグは除去されます。添付の更新は公開許可を得てから行い、実再生を確認し、README と対応表を同時に更新します。GitHub がプレーヤーを管理するため、自動再生、ループ、最終フレームの保持は保証されません。
- サイトでは、明示的な言語 URL、保存した手動選択、対応するブラウザーのコンテンツ言語、英語へのフォールバックの順に決定します。同じページ言語から対応動画を選びます。別の動画言語メニューは不要です。英語へのフォールバックは明記し、簡体字中国語を繁体字中国語訳と表示してはいけません。
- サイトの再生はミュートから始め、明示的なクリックでだけ音効を有効にします。一時停止・ミュート、表紙・手動再生の代替手段、動きを減らす設定への対応を残します。既定では最後のフレームで止まり、再生し直しと任意のループを提供します。JavaScript 無効時も MP4 への通常リンクを残します。
- 現在の八本はいずれも 40 秒で、短い動作音効を持ち、背景音楽はありません。終了時のブランド動作を最後まで見せた後、静止したエンドカードを表示します。終わりに冒頭を付け足しません。
- RelayRun-GitGuard-Intro-en-v12.mp4 のような予測可能な名前を使い、zh-CN、ja、de、fr、es、pt-BR、ru も対応させます。[動画素材と音源のクレジット](../../assets/videos/README.md)を参照してください。

<a id="before-adding-media-to-a-release"></a>

## 公開物に動画を含める前

書き出したフレーム、文字、メタデータ、素材の権利を調べます。映像・音声全体の長さ、デコード、実測サイズ、言語リンクを確認します。ブラウザーの実再生はファイル検査とは別であり、音声の数値検査は試聴を代替しません。チェッカーのバイナリー・サイズ超過の指摘は範囲を限定して人が確認し、全体で無効化しないでください。

選定した出力と必要なクレジットだけを配布します。編集用ソース、非公開証拠、原音録音、内部計画は公開文書パッケージに入れません。ローカルの読み取りプレビューは近似表示であり、GitHub 表示の検証ではありません。公開添付のアップロード、サイトへの組み込み、デプロイは別の操作です。
