<a id="homepage-placement-and-language"></a>

## Posição e idioma na página inicial

Coloque a apresentação de 40 segundos logo após a lista de idiomas do README, antes da introdução principal e do exemplo diário de quatro etapas. O título em inglês é “Git Guard in 40 seconds”; em chinês, “40 秒了解 Git Guard”. É uma apresentação do produto, não o tutorial completo de configuração.

Use o idioma do README escolhido. O README padrão em inglês aponta para o MP4 inglês; chinês simplificado e japonês apontam para seus respectivos MP4s. Não adicione um segundo seletor de idioma para vídeo. Mudar o README também escolhe seu vídeo. Alemão, francês, espanhol, português brasileiro e russo também usam seus filmes concluídos. As oito combinações README/vídeo estão neste pacote local.

<a id="delivery-and-playback"></a>

## Entrega e reprodução

- Entregue somente MP4. Mantenha a capa PNG como imagem vinculada, não como GIF animado. Composição editável, arte compartilhada e textos traduzidos separados ficam no espaço de produção; consumidores recebem as exportações selecionadas.
- Um README de repositório não executa JavaScript personalizado nem escolhe vídeo pelo idioma do navegador ou IP. Capa vinculada e link MP4 relativos funcionam como navegação normal de arquivos; não prometem player embutido no GitHub.
- Durante publicação GitHub autorizada separadamente, um vídeo enviado como anexo pode permitir reprodução embutida. Verifique a apresentação real e mantenha link de arquivo utilizável. Não envie mídia apenas para testar aparência. O GitHub controla seu player; não prometa autoplay, repetição ou retenção do quadro final ali.
- No site, determine o idioma por URL explícita, escolha manual salva, preferências de conteúdo compatíveis do navegador e, por fim, inglês como alternativa. Escolha o vídeo disponível correspondente ao mesmo idioma. Um menu separado para vídeo é desnecessário. Identifique claramente alternativa em inglês e não apresente chinês simplificado como tradução em chinês tradicional.
- A reprodução no site começa sem som. Ative efeitos apenas com clique explícito; mantenha pausa/silenciar, capa/reprodução manual alternativa e tratamento de movimento reduzido. A reprodução padrão termina no quadro final, com replay e repetição opcional. Sem JavaScript, mantenha links MP4 comuns.
- As oito exportações atuais têm 40 segundos, efeitos curtos de ação e nenhuma música de fundo. Preserve toda a animação final da marca seguida do cartão estático; não acrescente a abertura ao final.
- Use nomes previsíveis, como RelayRun-GitGuard-Intro-en-v12.mp4 e os correspondentes zh-CN, ja, de, fr, es, pt-BR e ru. Veja [vídeos e créditos de som](../../assets/videos/README.md).

<a id="before-adding-media-to-a-release"></a>

## Antes de incluir mídia numa publicação

Inspecione quadros exportados, texto, metadados e direitos dos recursos. Verifique duração completa de vídeo/áudio, decodificação, tamanho medido e links de idiomas. Reprodução real em navegador é separada dos testes de arquivos; medições de áudio não substituem escuta. Avisos de binário/tamanho do scanner exigem revisão manual delimitada; não os suprima globalmente.

Distribua apenas exportações escolhidas e créditos necessários. Fontes editáveis, evidências privadas, gravações brutas e planos internos não pertencem ao pacote público. Uma prévia local aproxima a apresentação e não certifica a renderização do GitHub. Envio de anexos públicos, integração ao site e implantação são ações separadas.
