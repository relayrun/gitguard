## Размещение и язык на главной странице

Разместите 40-секундный обзор сразу после списка языков README, перед основным введением и примером четырёх шагов. Английский заголовок — «Git Guard in 40 seconds», китайский — «40 秒了解 Git Guard». Это обзор продукта, а не полный урок настройки.

Используйте язык выбранного README. Английский README по умолчанию ссылается на английский MP4; упрощённый китайский и японский — на соответствующие им видео. Не добавляйте второй языковой переключатель для ролика. Смена README выбирает и его видео. Немецкий, французский, испанский, бразильский португальский и русский также используют готовые фильмы на своих языках. Все восемь пар README/видео включены в локальный пакет.

<a id="delivery-and-playback"></a>

## Формат поставки и воспроизведение

- Поставляйте только MP4. Сохраняйте PNG-обложки как повторно используемые файлы, а не анимированные GIF. Редактируемые композиции, общие материалы и переводы остаются в производственной среде; распространяются только выбранные экспорты.
- Каждый README GitHub встраивает видео своего языка с помощью URL видеовложения в отдельном абзаце и сохраняет ниже прямую ссылку для скачивания MP4. В описании медиаматериалов перечислены включённые MP4 и соответствующие языкам вложения. Другие средства просмотра Markdown могут показывать только ссылку.
- README не выполняет произвольный JavaScript и не выбирает видео по языку браузера или IP. Обложки со ссылками открывают файлы; обычные HTML-теги video удаляются. Заменяйте вложения только после разрешения на публикацию, проверяйте реальное воспроизведение и одновременно обновляйте README и таблицу. Проигрывателем управляет GitHub; автозапуск, повтор и удержание последнего кадра не гарантируются.
- На сайте выбирайте язык по явному языковому URL, сохранённому ручному выбору, поддерживаемым языковым предпочтениям браузера, затем английскому резервному варианту. По тому же языку страницы выбирайте доступный ролик. Отдельное меню языка видео не требуется. Явно отмечайте английский резервный вариант и не называйте упрощённый китайский переводом на традиционный.
- Веб-воспроизведение начинается без звука. Включайте эффекты только явным нажатием; сохраняйте паузу/выключение звука, обложку/ручной запуск и учёт уменьшенного движения. Обычное воспроизведение завершается на последнем кадре, с повтором и необязательным циклом. Без JavaScript должны работать обычные MP4-ссылки.
- Все восемь текущих экспортов длятся 40 секунд, содержат короткие звуковые эффекты действий и не имеют фоновой музыки. Сохраняйте всю финальную анимацию бренда и следующую за ней статичную заставку; не добавляйте начало ролика в конец.
- Используйте предсказуемые имена, например RelayRun-GitGuard-Intro-en-v12.mp4 и варианты zh-CN, ja, de, fr, es, pt-BR и ru. См. [видео и сведения об авторах звуков](../../assets/videos/README.md).

<a id="before-adding-media-to-a-release"></a>

## До добавления медиа в выпуск

Проверьте экспортированные кадры, текст, метаданные и права на материалы. Проверьте полную длительность видео/аудио, декодирование, измеренный размер и языковые ссылки. Фактическое воспроизведение в браузере — отдельная проверка; числовые измерения звука не заменяют прослушивание. Уведомления сканера о бинарных файлах/размере требуют ограниченной ручной проверки; не подавляйте их глобально.

Поставляйте только выбранные экспорты и необходимые сведения об авторах. Редактируемые исходники, приватные доказательства, сырые записи и внутренние планы не входят в публичный пакет документации. Локальный просмотр лишь приближённо показывает оформление и не удостоверяет отображение GitHub. Загрузка публичных вложений, интеграция с сайтом и развёртывание — отдельные действия.
