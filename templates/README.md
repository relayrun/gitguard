# Reusable templates

These are examples for adopters, not this project's private management records.

- [Change handoff](change-handoff.md): authorized local work, branch/PR handoff and human merge.
- [Security acceptance CSV](security-acceptance.csv): one row per actor, path and operation; replace the example row only with observed evidence.
- [Backup policy](backup-policy.md): independent synchronization, protected versions and selectable recovery checks.
- [Agent entry](agent-entry.example.md): a small entry linking an adopter's own authoritative rules.

Adapt the placeholders to your own repository. Keep real credentials, private identities and detailed evidence in an appropriately restricted location. The [workflow](../docs/en/workflow.md), [acceptance specification](../docs/en/security-acceptance.md) and [backup guide](../docs/en/backup-and-recovery.md) remain the shared rules.
